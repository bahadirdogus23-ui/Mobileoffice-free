# Örnek dosyalar

Uygulamayı denemek için **uydurma** bilgilerle hazırlanmış dosyalar. VKN, TCKN, ETTN ve firma adları gerçek değildir.

| Dosya | Ne için |
|---|---|
| `ornek-e-fatura.xml` | İçine gömülü satıcı tasarımı (XSLT) olan bir e-Fatura |
| `ornek-e-arsiv-tasarimsiz.xml` | Tasarımı olmayan bir e-Arşiv faturası; uygulamanın sade görünümü |
